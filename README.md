# kidBehaviour

PWA familiar para registrar las tarjetas diarias de Itzi e Iñigo.

## Reglas automáticas

- 3 tarjetas azules consecutivas: la tercera pasa a dorada.
- 2 tarjetas doradas en una semana: premio "Plan especial".
- 2 tarjetas doradas consecutivas: desactivan una consecuencia negra activa.
- 2 tarjetas rojas consecutivas: la segunda pasa a negra.

Los datos se guardan localmente en el dispositivo mediante localStorage.
